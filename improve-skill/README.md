# improve-skill

Audit a skill or command file against the instruction pattern catalog and produce specific, pattern-named rewrites.

## Context

LLMs are not always reliable advisors on what instructions an LLM will follow. If you ask Claude to "Write a skill that does x," you will likely end up with a set of instructions that look good to you, an intelligent human who knows what your intentions were, but that do not get executed at all consistently—never mind deterministically. Your DO's will get dropped, your DON'Ts will get done, and you might get asked to approve a couple dozen Bash calls, to get these annoying results.

But some skills work better than others! Github's [Spec Kit](https://github.com/github/spec-kit), for example, is more reliable than many: when you invoke it, you pretty consistently get the same behavior and outputs. So before I first drafted this prompt, I would repeatedly copy and paste into Claude, "Rewrite this skill using the same procedural check-then-act workflow employed in the `.claude/commands/speckit.*.md` files." When finally I got tired of that, I asked Claude to create `/catalog-instruction-patterns`, to extract those techniques into a pattern library. Then I had it create `improve-skill` to apply that library as a structured rubric: each issue found in the skill being improved is named, severity-rated, and paired with a concrete rewrite proposal rather than vague commentary.

## Usage

```
/improve-skill <path-to-skill-or-command-file>
```

Identifies missing patterns (STOP gates, output format specs, skip rules, etc.), misapplied patterns, and produces concrete rewrite proposals for High and Medium severity issues. Applies approved rewrites with targeted edits.

## First-time setup

This skill requires a pattern catalog file generated by `/catalog-instruction-patterns`. If the catalog doesn't exist at the configured path, the skill will prompt you to generate it.

To generate the catalog:

```
/catalog-instruction-patterns ~/.claude/skills
```

Save the output to the path configured by `IMPROVE_SKILL_CATALOG_PATH` (see below).

## Configuration

| Env var | Purpose | Default |
| --------- | --------- | --------- |
| `IMPROVE_SKILL_CATALOG_PATH` | Path to the instruction-patterns catalog file | `~/.claude/skills/improve-skill/instruction-patterns.md` |

Set in your Claude settings (`~/.claude/settings.json` or `.claude/settings.local.json`):

```json
{
  "env": {
    "IMPROVE_SKILL_CATALOG_PATH": "~/.claude/skills/improve-skill/instruction-patterns.md"
  }
}
```
