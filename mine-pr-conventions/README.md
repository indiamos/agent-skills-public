# mine-pr-conventions

Discover coding conventions from a GitHub repo's PR review history — surfacing what reviewers consistently flag without requiring a written style guide.

## Context

Written style guides are rarely complete or current. This skill extracts the unwritten norms that reviewers actually enforce by analyzing merged PR comments — capturing what gets flagged repeatedly and what the team approves without question. Useful before writing a formal CLAUDE.md or before contributing to an unfamiliar codebase.

## Usage

```
/mine-pr-conventions [repo-url-or-name]
```

Analyzes merged PRs and their review comments to extract recurring feedback patterns, naming conventions, and architectural preferences the team actually enforces.
